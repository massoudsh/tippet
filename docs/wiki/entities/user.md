# User

> کاربر پلتفرم؛ می‌تواند خریدار، فروشنده یا هر دو باشد.

## مسئولیت‌ها
- احراز هویت بر پایه‌ی شماره موبایل (OTP — پیاده‌سازی هنوز باز است، Issue #۱۹).
- نگهداری نقش (`BUYER`/`SELLER`/`BOTH`) و شهر.

## وابستگی‌ها
- [[entities/style-profile]] — یک‌به‌یک، فقط برای خریدار پر می‌شود.
- [[entities/item]] — یک فروشنده N آیتم دارد (relation `SellerItems`).
- [[entities/interaction]] — رفتار کاربر روی آیتم‌ها.

## قراردادها / Edge cases
- `phone` یکتا و اجباری؛ `name`/`city` اختیاری.
- کاربر می‌تواند هم‌زمان `BUYER` و `SELLER` باشد (`BOTH`) — UI باید هر دو پنل را نشان دهد.
- جزئیات OTP هنوز مشخص نشده (ریسک باز PRD بخش ۱۰؛ پیگیری Issue #۱۹).
